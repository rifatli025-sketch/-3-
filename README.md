# -3-
Проект представляет собой интерактивную карту мира с возможностью отображения городов по различным параметрам. Пользователь может выбирать города определённой страны, фильтровать их по плотности населения и одновременно использовать оба фильтра. Также реализован вывод дополнительной информации о городах: текущей погоды через Open-Meteo API
